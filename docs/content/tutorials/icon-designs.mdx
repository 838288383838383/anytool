# Icon Design Workshop

## Layer Composition

### Background Layer
Start with a solid background shape:
- Circle for most icons
- Squircle for modern look
- Rounded square for compatibility

### Foreground Layer
Add your main design element:
- Text characters (single letter or emoji)
- Imported images
- Geometric shapes

### Overlay Layer
Apply finishing effects:
- Gradient overlay for depth
- Subtle shadow for dimension
- Pattern for texture

## JSON Design Format

```json
{
  "name": "My Design",
  "author": "YourName",
  "version": 1,
  "background": {
    "shape": "squircle",
    "color": "#2196F3",
    "gradient": {
      "type": "linear",
      "start": [0, 0],
      "end": [1, 1],
      "colors": ["#2196F3", "#1976D2"]
    }
  },
  "layers": [
    {
      "type": "text",
      "text": "AT",
      "font": "sans-serif-bold",
      "size": 140,
      "color": "#FFFFFF",
      "position": [0.5, 0.5]
    }
  ],
  "overlay": {
    "type": "gradient",
    "opacity": 0.1,
    "colors": ["#FFFFFF", "#000000"]
  }
}
```

## Community Sharing

1. Export your design as JSON
2. Share on GitHub or community forums
3. Others can import via Settings → Import Design

## Best Practices

- Keep designs simple — icons are small
- Test at multiple sizes (48dp, 72dp, adaptive)
- Use high contrast colors for readability
- Name your designs descriptively
