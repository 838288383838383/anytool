# Stress Test

Benchmark your device's performance across CPU, memory, storage, and network.

## CPU Stress Test

### Single-Core Test
- Tests single-thread performance
- Useful for comparing individual core speeds
- Measures operations per second

### Multi-Core Test
- Uses all available CPU cores simultaneously
- Tests thermal throttling under sustained load
- Shows maximum multi-thread performance

### Duration
- Short: 30 seconds
- Medium: 2 minutes
- Long: 5 minutes (tests thermal management)

## Memory Stress Test

- Allocates and accesses large memory blocks
- Tests RAM bandwidth and latency
- Identifies memory-related performance issues

## Storage I/O Test

### Sequential Read/Write
- Measures sustained transfer speeds
- Useful for large file operations

### Random Read/Write
- Tests IOPS (Input/Output Operations Per Second)
- Reflects real-world app performance

## Network Bandwidth Test

- Download speed test
- Upload speed test
- Latency (ping) measurement

## Thermal Monitoring

During stress tests, AnyTool monitors:
- CPU temperature
- Battery temperature
- Throttling events

> **Tip:** Run the long CPU test to see how your device handles sustained workloads. Compare results before and after kernel tweaks.
