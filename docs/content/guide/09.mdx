# App Manager

A comprehensive app management tool powered by Shizuku.

## Features

### App Listing
- View all installed apps (system + user)
- See package name, version, install date, size
- Sort by name, size, install date, or last used

### App Actions
- **Uninstall** — Remove user apps (or system apps with root)
- **Disable** — Disable system apps without uninstalling
- **Clear Data** — Wipe app cache and data
- **Force Stop** — Immediately terminate the app
- **Export APK** — Save the APK file to storage

### App Details
- Permissions list with grant status
- Components (activities, services, receivers, providers)
- Target SDK, min SDK, version code
-签名信息 (signature info)
- Shared libraries and native code

## Batch Operations

Select multiple apps to:
- Uninstall/Disable in batch
- Clear data for multiple apps
- Export APKs in bulk

> **Tip:** Use batch disable to quickly debloat without the full Debloater mode.
