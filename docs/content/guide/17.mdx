# Volume Manager

Use volume button shortcuts to quickly launch apps and perform actions.

## How It Works

AnyTool registers as an Accessibility Service to intercept volume button presses:

- **Volume Up 2x quickly** → Opens AnyTool launcher
- Custom shortcuts for other volume patterns

## Setup

1. Open AnyTool → tap **Volume Manager**
2. Tap **Enable Service**
3. Grant Accessibility Service permission in Android Settings
4. Configure your shortcuts

## Configuring Shortcuts

### 5 Available Slots

Each slot can be configured with:
- **App** — Launch any installed app
- **Action** — Toggle WiFi, hotspot, flashlight, etc.
- **Volume Level** — Set a specific volume level when triggered

### Per-Shortcut Volume

Set a custom media volume for each shortcut:
- Silent (0)
- Low (25%)
- Medium (50%)
- High (75%)
- Max (100%)

## Testing

Use the test mode to verify your shortcuts work without leaving the configuration screen.

> **Warning:** Accessibility Services consume minimal battery but have broad device access. Only grant to trusted apps.
