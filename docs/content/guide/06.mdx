# System Tweaks

System Tweaks lets you modify Android system settings that normally require root or ADB — all powered by Shizuku.

## Available Tweaks

### Display
- **Animation Scale** — Speed up or disable system animations (0.5x, 1x, 2x, off)
- **DPI Override** — Change display density for more/fewer items on screen
- **Always-On Display** — Toggle AOD (device-dependent)

### Audio
- **Volume Steps** — Increase volume control granularity (15 → 30 steps)
- **Safety Volume Bypass** — Remove high-volume warnings (use responsibly)

### Network
- **Mobile Data Always Active** — Keep data connection during WiFi
- **DNS Over HTTPS** — Configure encrypted DNS

### Developer
- **USB Debugging** — Toggle without Developer Options
- **Show Layout Bounds** — Debug UI layouts
- **GPU Rendering** — Force GPU rendering for all apps

## How to Apply

1. Open AnyTool → tap **System Tweaks**
2. Browse categories or search
3. Tap a tweak to toggle or configure
4. Changes take effect immediately (some may require reboot)

> **Tip:** Changes are tracked. You can revert all tweaks from the System Tweaks settings.
