# App Launcher

Launch any installed app quickly from a unified interface.

## Features

### App Grid
- View all installed apps in a scrollable grid
- App icons with labels
- Sorted alphabetically or by usage frequency

### Search
- Real-time search as you type
- Search by app name or package name
- Keyboard shortcut support

### Theme Support
- Follows AnyTool's theme system
- 9 built-in themes (Frutiger Aero, Catppuccin, Nord, etc.)
- Consistent Material 3 styling

## Actions

- **Tap** — Launch the app
- **Long Press** — View app details (package name, version, permissions)
- **Swipe** — Quick disable/uninstall (configurable)

## Usage

1. Open AnyTool → tap **App Launcher**
2. Browse or search for the app
3. Tap to launch

> **Tip:** Pin frequently used apps to the top by marking them as favorites.
