# Battery Stats

Monitor your device's battery health, usage patterns, and charging status.

## Battery Information

### Health Details
- **Health** — Good, Overheat, Dead, Unknown
- **Temperature** — Current battery temperature in °C/°F
- **Voltage** — Current voltage in mV
- **Technology** — Battery type (Li-ion, Li-poly, etc.)

### Capacity
- **Design Capacity** — Original manufacturer capacity (mAh)
- **Current Capacity** — Actual remaining capacity
- **Health Percentage** — Current vs design capacity ratio

### Charging Status
- **Status** — Charging, Discharging, Full, Not Charging
- **Plugged** — AC, USB, Wireless, or None
- **Level** — Current percentage (0-100%)

## Usage Statistics

### Per-App Battery Usage
- See which apps consume the most battery
- View foreground vs background usage
- Compare usage over 24h, 7 days, or since last charge

### System Usage
- Screen-on time
- WiFi vs mobile data usage
- Bluetooth and sensor usage

## Battery History

Graph showing battery level over time with markers for:
- Screen on/off events
- Charging start/stop
- App activity spikes
- System sleep/wake cycles

> **Tip:** High battery drain in sleep mode usually indicates a rogue app or service.
