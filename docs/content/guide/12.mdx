# Network Info

View detailed information about all network connections on your device.

## WiFi Information

### Connection Details
- **SSID** — Connected network name
- **BSSID** — Access point MAC address
- **IP Address** — IPv4 and IPv6 addresses
- **Gateway** — Router IP address
- **DNS** — Configured DNS servers

### Signal Information
- **Signal Strength** — dBm and percentage
- **Link Speed** — Current connection speed (Mbps)
- **Frequency** — 2.4 GHz or 5 GHz band
- **Channel** — WiFi channel number

## Cellular Information

- **Network Type** — 4G, 5G, LTE, etc.
- **Cell ID** — Current cell tower identifier
- **Signal Strength** — dBm and ASU
- **Roaming** — Whether you're on a roaming network

## Active Connections

View all active network connections:
- **Local Address** — Your device's IP and port
- **Remote Address** — Connected server IP and port
- **State** — ESTABLISHED, TIME_WAIT, LISTEN
- **Process** — Which app owns the connection

> **Tip:** Use this to identify apps making unexpected network connections.
